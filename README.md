# Tópicos de Inteligencia Artificial

Este repositorio contiene el desarrollo de un proyecto de reconocimiento facial aplicado al ámbito educativo, integrando técnicas de visión artificial, aprendizaje automático y desarrollo móvil.

## Estructura del Repositorio

###  app_flutter

Contiene la aplicación móvil desarrollada en Flutter y Dart.

La aplicación permite la interacción con el usuario y la visualización de la información obtenida por el sistema de reconocimiento facial. Entre sus principales funciones se encuentran:

- Captura de imágenes mediante la cámara del dispositivo.
- Procesamiento de resultados del reconocimiento facial.
- Visualización de información académica del estudiante.
- Interfaz multiplataforma desarrollada con Flutter.

Tecnologías utilizadas:

- Flutter
- Dart
- TensorFlow Lite
- Android Studio

## Objetivo del Proyecto

Desarrollar una aplicación móvil capaz de identificar estudiantes mediante reconocimiento facial, mostrando información académica asociada como:

- Identificador del estudiante.
- Nombre completo.
- Carrera.
- Semestre.

El sistema busca demostrar la integración de técnicas de visión artificial y aprendizaje automático en un entorno educativo mediante una solución móvil funcional.
